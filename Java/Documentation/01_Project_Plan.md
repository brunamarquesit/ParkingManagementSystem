
# Parking Management System
## Project Plan

**Unit:** ICTPRG532 – Apply Advanced Object-Oriented Language Skills

**Project:** Parking Management System

### 1. Project Overview

The Parking Management System is a software application developed using Java and C++.

The system is designed to manage vehicle parking, allocate parking spaces, search for registered vehicles, remove vehicles, and display parking availability.

The application supports three types of vehicles: motorcycles, cars, and buses.

### 2. Project Objectives

The main objectives of this project are:

- Apply object-oriented programming principles.
- Implement inheritance, abstraction, and polymorphism.
- Manage parking spaces across multiple levels and rows.
- Allocate appropriate parking spaces for different vehicle types.
- Use data structures and searching and sorting algorithms.
- Demonstrate communication mechanisms using Java.
- Develop a graphical user interface.
- Test the application and document the results.


### 3. Project Requirements

The Parking Management System includes the following requirements:

**Vehicle Management**
- Register motorcycles, cars, and buses.
- Search for vehicles using their registration plates.
- Remove registered vehicles from the parking system.
- Display vehicle information.

**Parking Space Management**
- Organise parking spaces across multiple levels and rows.
- Identify available and occupied parking spaces.
- Allocate suitable spaces according to vehicle type.
- Allocate five consecutive large spaces for buses.
- Release parking spaces when vehicles are removed.

**Object-Oriented Programming**
- Use classes and objects.
- Apply inheritance, abstraction, and polymorphism.
- Implement vehicle subclasses.

**Data Structures and Algorithms**
- Implement a doubly linked list.
- Implement a binary tree.
- Implement a hash table.
- Demonstrate searching and sorting algorithms.

**Java Features**
- Demonstrate shared-memory communication between threads.
- Demonstrate message passing using a blocking queue.
- Implement client-server communication using Java sockets.
- Create a graphical user interface with drag-and-drop.
- Display parking spaces using 2D graphics.
- Provide a Help feature for users.

**Testing and Documentation**
- Test the main application functions.
- Record test results and screenshots.
- Document the system design, implementation, and testing.


### 4. Technologies and Tools

The following technologies and tools were used in the project:

- **Java:** Object-oriented programming, data structures, algorithms, graphical user interfaces, multithreading, and socket communication.
- **C++:** Vehicle management, inheritance, polymorphism, and parking space allocation.
- **Java Swing:** Graphical user interface and drag-and-drop functionality.
- **Java 2D:** Graphical representation of parking spaces.
- **Java Sockets:** Client-server communication.
- **Visual Studio Code:** Source code development and testing.
- **G++ Compiler:** Compilation of the C++ application.
- **PowerShell:** Execution and testing of the applications.
